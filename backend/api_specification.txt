Định dạng dữ liệu: RESTful API / JSON
Bảo mật hệ thống: Yêu cầu Header 'Authorization: Bearer <JWT_TOKEN>' cho mọi API.

--------------------------------------------------------------------------------
1. MODULE AUTHENTICATION & USER PROFILE
--------------------------------------------------------------------------------

1.1. Đăng ký tài khoản
* HTTP Method: POST
* Endpoint: /api/v1/auth/register
* Mô tả: API tạo tài khoản mới.
* Response Body (200 OK):
{
  "success": true,
  "message": "Tạo tài khoản thành công"
}

1.2. Đăng nhập
* HTTP Method: POST
* Endpoint: /api/v1/auth/login
* Mô tả: API đăng nhập và cấp phát JWT Token.
* Response Body (200 OK):
{
  "success": true,
  "message": "Đăng nhập thành công"
}

1.3. Lấy thông tin hồ sơ và ví Credit
* HTTP Method: GET
* Endpoint: /api/v1/users/profile
* Mô tả: Trả về thông tin cá nhân, số dư ví và trạng thái gói cước hiện tại của cán bộ.
* Response Body (200 OK):
{
  "id": 10293,
  "email": "canbo.nguyenvan@coquan.gov.vn",
  "fullName": "Nguyễn Văn A",
  "agency": "Văn phòng Tỉnh ủy",
  "role": "ROLE_USER",
  "creditBalance": 350,
  "packageType": "PROFESSIONAL",
  "expireDate": "2026-12-25T23:59:59",
  "affiliate": {
    "code": "VANPHONG_AI_A102",
    "link": "https://trolyai.vn/register?ref=VANPHONG_AI_A102",
    "totalEarnings": 1250000
  }
}

1.4. Lấy danh sách lịch sử văn bản gần đây (Recent Documents)
* HTTP Method: GET
* Endpoint: /api/v1/users/documents?page=0&size=10
* Mô tả: Lấy danh sách các phiên làm việc gần nhất phục vụ khối "Văn bản đang xử lý".
* Response Body (200 OK):
{

2. MODULE WORKSPACE & ASSISTANT MENU
--------------------------------------------------------------------------------

2.1. Khởi tạo một phiên làm việc mới (Khi bấm vào một mục Trợ lý)
* HTTP Method: POST
* Endpoint: /api/v1/chat-sessions
* Request Body:
{
  "tagId": "dang_tinh_uy", 
  "sessionName": "Khởi tạo văn bản mới"
}
* Response Body (201 Created):
{
  "sessionId": 502,
  "tagId": "dang_tinh_uy",
  "sessionName": "Khởi tạo văn bản mới",
  "currentEditorContent": "",
  "createdAt": "2026-06-04T23:15:00"
}

2.2. Đồng bộ/Lưu nội dung từ Editor vào Database
* HTTP Method: PUT
* Endpoint: /api/v1/chat-sessions/{sessionId}/editor
* Request Body:
{
  "htmlContent": "<h1>ĐẢNG CỘNG SẢN VIỆT NAM</h1><p>Nghị quyết hội nghị lần thứ...</p>"
}
* Response Body (200 OK):
{
  "success": true,
  "message": "Đã lưu bản nháp văn bản thành công"
}

3. MODULE FORM WIZARD WORKFLOW (Thu nhập thông tin đầu vào)
--------------------------------------------------------------------------------

3.1. Upload tài liệu đầu vào (Hỗ trợ đa định dạng)
* HTTP Method: POST
* Endpoint: /api/v1/files/upload
* Content-Type: multipart/form-data
* Form Data:
  - file: (Binary File: .docx, .pdf, .txt)
  - category: "INPUT_DIRECTIVE" (Văn bản chỉ đạo) hoặc "EVIDENCE" (Tài liệu minh chứng)
* Response Body (200 OK):
{
  "success": true,
  "message": "Tải file thành công",
  "data": {
    "fileId": "file_15",
    "fileName": "Cong_van_302_TUV.pdf",
    "fileUrl": "https://storage.trolyai.vn/inputs/20240619123000123_Cong_van_302_TUV.pdf",
    "fileSize": 1542300,
    "category": "INPUT_DIRECTIVE",
    "uploadedAt": "2026-06-19T12:30:00",
    "uploadedBy": "Nguyễn Văn A"
  },
  "statusCode": 200
}

3.2. Tính toán Credit tạm tính (Cơ chế Hold tiền trước khi chạy lệnh)
* HTTP Method: POST
* Endpoint: /api/v1/credits/estimate
* Request Body:
{
  "modelName": "claude-sonnet-4.6",
  "features": ["LEGAL_REVIEW", "EXPORT_DOCX"],
  "fileId": "file_15"
}
* Notes:
  - fileId hỗ trợ cả định dạng "file_15" hoặc "15".
  - Nếu fileId không parse được, trả lỗi 400 Bad Request với thông báo "fileId không hợp lệ".
  - Nếu fileId thuộc về user khác, trả 403 Access Denied.
* Response Body (200 OK):
{
  "success": true,
  "message": "Ước tính credit thành công",
  "data": {
    "estimatedCredits": 6.5,
    "currentCredits": 10.0,
    "isEligible": true,
    "inputCreditEstimate": 4.0,
    "outputCreditEstimate": 2.5,
    "totalCreditHold": 6.5
  },
  "statusCode": 200
}

4. MODULE AI STREAMING & OPERATIONS (Không gian Workspace)
--------------------------------------------------------------------------------

4.1. Gửi lệnh tạo/sửa văn bản với AI (Luồng Real-time Stream)
* HTTP Method: POST
* Endpoint: /api/v1/ai/completions
* Headers: Accept: text/event-stream (Server-Sent Events)
* Request Body:
{
  "sessionId": 502,
  "wizardStateJson": "{\"step1\": {\"docType\": \"Nghị quyết\", \"title\": \"Nghị quyết phát triển kinh tế\"}}",
  "promptCommand": "Hãy chỉnh sửa lại đoạn văn bản hiện tại trang trọng hơn và rà soát lỗi chính tả.",
  "pinEditorContext": true, 
  "model": "claude-sonnet-4.6"
}
* Server-Sent Events Stream Output:
data: {"type": "content", "text": "### 1. VĂN BẢN HOÀN CHỈNH\n..."}
data: {"type": "content", "text": "### 4. GHI CHÚ KIỂM TRA TRƯỚC KHI TRÌNH KÝ\n..."}
data: {"type": "verify_done", "actualCreditDeducted": 4.1, "refundedCredit": 0.4, "currentBalance": 345.9}

4.2. Xuất bản văn bản hành chính (.docx, .pdf, .xlsx)
* HTTP Method: POST
* Endpoint: /api/v1/ai/exporter/export
* Request Body:
{
  "sessionId": 502,
  "exportFormat": "DOCX", 
  "htmlContent": "<h1>ĐẢNG CỘNG SẢN VIỆT NAM...</h1>"
}
* Response: Trả về ứng dụng luồng nhị phân (Application/Octet-Stream) để kích hoạt download file.
